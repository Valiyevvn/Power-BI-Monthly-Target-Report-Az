# Power-BI-Monthly-Target-Report-Az
Power BI-da hazırladığım bu interaktiv dashboard satış komandasının və əməkdaşların aylıq hədəf icraatlarını (H/G faizi) izləmək üçündür. Layihədə dinamik işçi profilləri, DAX ilə hesablanmış KPI-lar, Top 8 performans liderləri sıralaması və rahat navigation tab-ları istifadə olunub. Məlumat modeli və dizayn tam sıfırdan yığılıb.
